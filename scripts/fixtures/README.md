# Screenshot fixture

The gallery script uploads `great-wave.jpg` into its temporary feed. The image is a public-domain reproduction of *Under the Wave off Kanagawa* by Katsushika Hokusai, from the Metropolitan Museum of Art's Open Access collection (object 45434). The local fixture keeps regeneration independent of a third-party image service. [Collection record](https://www.metmuseum.org/art/collection/search/45434) · [Open Access policy](https://www.metmuseum.org/policies/image-resources)
